# SeatCraft 座位小幫手

給國中老師用的排座位工具。在瀏覽器裡設定教室和條件，按一下就排好座位。

- **不需要安裝**：雙擊 `index.html` 就能用。
- **不需要網路**：所有計算都在你的電腦上完成，學生資料不會傳出去。

## 下載與使用

1. 到 [Releases](https://github.com/ITE-Richard/SeatCraft/releases) 下載最新版的 `SeatCraft-vX.Y.Z.zip`，解壓縮。
2. 打開 `SeatCraft` 資料夾，雙擊 **index.html**。建議使用 Chrome 或 Edge。
3. 畫面右上角的「使用說明」有完整的操作步驟。

> 複製到其他電腦時，請複製**整個資料夾**。程式需要 `index.html` 和 `src/` 一起放，只複製 `index.html` 無法使用。

## 功能

| 功能 | 說明 |
|---|---|
| 教室形狀 | 自己設定幾列（前到後）、幾排（左到右），點格子標記 **X** 表示不坐學生 |
| 不能坐在一起 | 兩人或一群人，任兩人都不會前後左右或斜對角相鄰 |
| 指定位置 | 第一列、最後一列、最左排、最右排，每人最多指定一區 |
| 身高印象 | 標記「偏高」「偏矮」即可，不用知道確切身高。盡量讓偏高的坐後半部，而且不擋到偏矮的同學 |
| 兩種輸入方式 | 點選學生號碼後按按鈕，或直接貼上文字條件 |
| 再排一次 | 每按一次就換一種排法 |
| 手動調整 | 點兩個座位就能互換；違反條件的座位會標紅框並說明原因 |
| 輸出 | 列印座位表、匯出 CSV（可用 Excel 開啟）或 Markdown |
| 存檔 | 自動暫存在瀏覽器；也可存成設定檔，帶到別台電腦載入 |

### 貼上文字條件的範例

```
15號, 14號不能一起坐
1, 11, 6, 13, 21 這一群是愛講話的同學, 不能坐一起
24坐第一列
20坐最後一列
3, 7, 12 比較高
5, 9 比較矮
```

### 規則怎麼算

- **用詞**：「列」是橫的（前後），「排」是直的（左右）。左右以學生面向講桌為準，也就是畫面上的左右。
- **優先順序**：
  1. 「不能坐在一起」和「指定位置」一定要做到。
  2. 身高是盡量做到：先讓偏高的坐後半部，再避免偏高的坐在偏矮的正前方 1～2 個座位。
  3. 人數比座位少時，空位會留在後面。
- **排不出來時**：程式會說明是哪一條條件衝突，例如「指定坐最左排的有 6 人，但最左排只有 5 個座位」。

## 開發

純 HTML／CSS／JavaScript，沒有任何外部套件，也不需要建置流程。

```
index.html          頁面與使用說明
src/classroom.js    教室形狀、座位編號、區域與相鄰關係
src/validator.js    排之前的矛盾檢查、排之後的違規檢查
src/solver.js       排座位：回溯搜尋（MRV＋前向檢查）＋隨機重新開始
src/height.js       身高與空位的改善（只做不違反硬條件的調整）
src/rules.js        解析老師貼上的文字條件
src/ui.js           畫面互動
tests/              測試（Node 內建 node:test）
docs/DESIGN.md      設計與模組介面
```

執行測試（需要 Node.js 18 以上）：

```
node --test
```
